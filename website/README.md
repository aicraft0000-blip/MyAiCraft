# The myaicraft.uk website

Plain HTML pages, so there's nothing to build. Upload the folder to any static host.

The pages call the companion and marketplace workers at `*.YOUR-SUBDOMAIN.workers.dev`. Change those to your own worker addresses, and change `hello@example.com`, `[COMPANY NUMBER]` and the Stripe links to your own details.

The privacy policy and terms were written for my company. If you run your own version, write your own.
